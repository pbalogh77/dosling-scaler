# Contributing

Use issues for bugs and pull requests for changes. Include your OS/compiler, scaler revision, model hash, the smallest redistributable reproduction and expected/actual output. Do not attach proprietary game files, private screenshots, credentials or personal feedback without permission.

Build and run the portable suite before proposing changes. Keep the C ABI stable or document changes. Keep HQ3x provenance and the LGPL shared-library boundary clear. Add focused synthetic regressions for geometry changes and compare text and graphics; do not claim an incomplete evaluation as complete. Describe any AI assistance honestly and review generated code before submission. Contributions are under LGPL-2.1-or-later; retain third-party notices. No CLA is currently required.
